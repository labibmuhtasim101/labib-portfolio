# Labib Muhtasim — Professional Terminal Portfolio

Static responsive portfolio website for online hosting.

## Upload
Upload the entire folder to GitHub Pages, Netlify, Vercel, or another static host. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.

## Notes
- Dark/light theme included.
- Technology and certification logos use scalable online SVG assets.
- Project screenshots are bundled locally in `assets`.
- `labib-cutout.png` is the supplied portrait prepared for the hero section.
- See `LOGO-SOURCES.txt` for logo sources.
